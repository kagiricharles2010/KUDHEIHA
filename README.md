# 2025–2029 CBA Pay Estimator (KUDHEIHA)

An unofficial, anonymous estimator of new basic pay, arrears and take-home for KUDHEIHA Workers (Grades 1–4) in public universities and constituent colleges. It's based on the Return to Work Formula signed on 30 October 2026.

- One HTML page; everything runs in the browser. Nothing entered is stored or sent, and the form clears on refresh.
- Schedule I salary tables: all 240 figures were transcribed from the signed RTWF and checked against the 3.5% annual and 5% increment rules.
- Same method as the UASU and KUSU estimators: https://kagiricharles2010.github.io/cba-estimator/
